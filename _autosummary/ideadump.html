ideadump#

ideadump: a place to dump ideas, research them a little, and find them again.

Capture an idea in the owner’s own words, attach research notes (a light pass at capture, a deep one when it looks promising), tag and link ideas, and ask which ideas relate to a query or to a page describing recent work. Ideas live in a dol store, by default a local folder, optionally a checkout of a private git repository.

>>> from ideadump import add, find
>>> files = {}
>>> _ = add("Offline speech to text on the phone", tags="audio", files=files)
>>> find("speech recognition", files=files)["hits"][0]["tags"]
['audio']

The command line (ideadump --help) and the agent skill shipped in ideadump/data/skills/ideadump drive the same verbs.

ideadump.add(words, *, title=None, summary=None, tags=None, source=None, status='new', files=None, data_dir=None, now=None)[source]#

Capture an idea: the owner’s words verbatim, plus an optional title, summary and tags.

words is kept exactly as given (dictation slips included); put the cleaned-up reading in summary. tags is comma-separated. source says where it was captured (a session name, “phone”). Returns the new id.

Return type:

dict

ideadump.find(query=None, *, file=None, limit=10, files=None, data_dir=None, score=None)[source]#

Ideas related to a query, best first: a few words, or a page of text in file.

For “is anything I’ve been working on related to my ideas?”, put a description of recent work (ledgers, issue titles, commit subjects) in a file and pass --file. Each hit lists the words it shares with the query, so a weak match is visible.

ideadump.sync(*, message=None, data_dir=None)[source]#

Commit every change in the data root, rebase onto the remote, push (no-op when not a git checkout).

Refuses while any record does not parse. After the rebase the pages are regenerated from the merged records and pushed again if they changed.

Return type:

dict

ideadump.sync_init(repo, *, dry_run=False, data_dir=None)[source]#

Make the data root a checkout of the private GitHub repository repo (owner/name).

Creates the repository, private, when it does not exist; refuses one that is not private. An existing ideas folder is adopted (committed and pushed); a folder that is already a checkout of a different repository is refused.

Return type:

dict
