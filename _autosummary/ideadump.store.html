ideadump.store#

Where ideas live: a MutableMapping of /-separated path to text.

Every verb takes a files store, so the default local folder can be swapped for any other dol store (or a plain dict in tests) without touching the rest. The default is a folder, the data root:

  1. the data_dir argument, else

  2. $IDEADUMP_DATA_DIR, else

  3. ~/.local/share/ideadump ($XDG_DATA_HOME and %LOCALAPPDATA% honoured).

To keep ideas in a private git repository, make the data root a checkout of it with ideadump sync-init <owner>/<name> (see ideadump.sync); the store itself does not change.

>>> data_dir("somewhere").is_absolute()
True

ideadump.store.writing(files=None, *, data_dir_=None, timeout=30.0)[source]#

The store, held exclusively while a verb reads, changes and rewrites it.

Several sessions may capture ideas at the same moment; each write verb reads every record, picks a free id, and rewrites the index, so two of them interleaving would lose an idea. For the default folder store this takes a lock file in the data root (created exclusively, so it works on every platform); a store passed in by the caller is the caller’s to serialise.

Return type:

Iterator[MutableMapping[str, str]]
