ideadump.semantic#

A semantic scorer for ideadump.search.rank(), backed by the fleet’s ir.

BM25 (the default, standard library, no network, no model) misses ideas that share meaning but not words. hybrid_scorer() adds embedding similarity from ir’s embedders, blended with BM25 so an exact word match still counts. It needs the semantic extra (ir); with the "light" embedder it needs no model download (a numpy hashing embedder, lexical in spirit), while the default is a local sentence-transformers model.

>>> scorer = hybrid_scorer("light")
>>> scores = scorer("offline speech to text", ["speech to text on a phone", "bread recipe"])
>>> scores[0] > scores[1]
True

resolve_scorer() maps the names a command line or environment variable can carry ("bm25", "semantic", "light", or any sentence-transformers model name) to a scorer, so the CLI needs no code of its own.

ideadump.semantic.hybrid_scorer(embedder='default', *, weight=0.5, cosine_floor=0.2)[source]#

A score(query, docs) blending BM25 with ir-embedding cosine similarity.

Parameters:

  • embedder – an ir embedder spec: "default" (local model), "light" (hashing, no download), or a model name.

  • weight (float) – share of the embedding score in the blend, in [0, 1].

  • cosine_floor (float) – cosine below which a document counts as unrelated.

Raises:

IdeadumpError – if ir (the semantic extra) is not installed.

Return type:

Callable[[str, Sequence[str]], list[float]]

ideadump.semantic.resolve_scorer(name=None)[source]#

The scorer for name, or None for the BM25 default.

name falls back to the SCORER_ENV_VAR environment variable, then to "bm25". "semantic" is the hybrid with ir’s default local model, "light" the hybrid with the hashing embedder, and any other string the hybrid with that embedder (a model name).

Return type:

Callable | None
